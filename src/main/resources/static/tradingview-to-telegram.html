How to Send TradingView Alerts Directly to Telegram via Webhooks

Real-time execution speed matters when trading intraday breakouts, RSI divergences, or algorithmic Pine Script strategies. While TradingView offers SMS and email notifications, Telegram alerts provide zero-latency mobile notifications with custom trade signal cards.

With NotifyU, you can relay alerts from TradingView straight to your personal Telegram or private trading channel for free—without spinning up Heroku apps or AWS Lambda relays.

🚀 Connect TradingView to Telegram Bot

3-Step Setup Guide

1 Get your dedicated TradingView Webhook URL

Open @notifyubot on Telegram and send the command /tradingview. The bot will return your unique URL:

https://notifyu.me/tradingview?uid=YOUR_UID&key=YOUR_KEY

2 Configure Webhook in TradingView

1. Open your chart on TradingView (NIFTY, BankNifty, Crypto, or Forex).
2. Click the Alert (Clock) icon to add an alert.
3. Under the Notifications tab, check the Webhook URL box.
4. Paste your NotifyU TradingView URL into the input field.

3 Choose Plain Text or Structured JSON Signals

You can send simple text alerts or formatted JSON parameters:

Example A: Plain Text Alert

NIFTY 15m RSI Overbought! Price crossed 25,400. Prepare to short.

Example B: Dynamic JSON Trading Card (Recommended)

{
  "ticker": "{{ticker}}",
  "action": "BUY",
  "price": "{{close}}",
  "message": "Supertrend Bullish Flip 5m"
}

NotifyU automatically parses these parameters and formats them into a high-visibility trading signal card in Telegram.
