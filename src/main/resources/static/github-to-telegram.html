Receive GitHub Commits and Releases on Telegram

Tracking repository activity, pull requests, and production deployments shouldn't require keeping an open browser tab or checking cluttered developer email inboxes. By routing GitHub webhooks to Telegram, solo developers and engineering teams receive instant push notifications whenever code is merged.

🐙 Get GitHub Webhook on Telegram

Setting Up GitHub Webhooks in 60 Seconds

1 Grab your Webhook URL from Telegram

Send /github to @notifyubot. You will receive your dedicated endpoint:

https://notifyu.me/webhook?uid=YOUR_UID&key=YOUR_KEY

2 Add the Webhook in GitHub

1. Open your repository on GitHub.
2. Click on Settings → Webhooks → Add webhook.
3. Paste your NotifyU URL into the Payload URL field.
4. Set Content type to application/json.
5. Under events, select Just the push event (or choose specific events like Releases, PRs, and Issues).
6. Click Add webhook.
