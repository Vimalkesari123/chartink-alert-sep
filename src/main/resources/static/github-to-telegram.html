3-Step Setup

1

Get Your GitHub Webhook URL

Open @Notifyu1_bot and send /github to get your dedicated webhook endpoint.

2

Add Webhook in GitHub

Go to your GitHub repo → Settings → Webhooks → Add webhook, paste your URL, and select application/json.

3

Get Instant Push Alerts

Every git commit, branch merge, or pull request triggers an immediate Telegram notification card.

Frequently Asked Questions

Does NotifyU require GitHub permissions or tokens?

No! NotifyU works via GitHub's standard outgoing webhooks. We never request access to your code, private keys, or account credentials.

Can I track multiple repositories?

Yes. You can paste your unique webhook URL across as many GitHub repositories as you need, and all notifications will route into your Telegram.
