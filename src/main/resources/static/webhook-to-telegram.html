Frequently Asked Questions

Can I send raw text instead of JSON?

Yes! NotifyU supports both structured JSON and plain-text strings. If you send plain text, it delivers the raw alert message intact.

What platforms are supported?

Any platform or programming language capable of sending an HTTP POST request can use this webhook (Stripe, Razorpay, Zapier, Make, Python, Node.js, Go, cURL, Grafana, and more).
